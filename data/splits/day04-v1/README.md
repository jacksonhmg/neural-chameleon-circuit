## Reproduce and verify

The ignored Day 1 upstream checkout must be present and must match its pinned hashes.

```bash
python3 scripts/day04_freeze_splits.py --check
PYTHONPATH=src python3 scripts/day04_verify_splits.py
```

The first command deterministically reconstructs all generated bytes in memory and compares them with the tracked freeze. The second performs structural, provenance, balance, disjointness, and lock checks. Neither command loads the model, loads a probe, or computes a safety result.

Project code should load benign data through:

```python
from neural_chameleon import load_experimental_split

discovery = load_experimental_split("discovery")
validation = load_experimental_split("validation")
```

The same loader fails closed for `safety-test` until the confirmatory-phase authorization described in `SAFETY_LOCK.md` exists.
