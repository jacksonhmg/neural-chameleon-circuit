# Decision 0031: Adopt a Post–Gate 1 Mechanism Re-identification Plan

- **Date:** 2026-08-09
- **Status:** Accepted for planning; execution not authorized

## Context

Decision 0030 correctly sealed the original acquired-writer gate as a scientific failure. That gate falsified the hypothesis that natural K12 trajectories form a complete example-specific writer representation of downstream layer-12 displacement and monitor effects. It did not test every causal operation compatible with the broader target title.

The sealed component decomposition also indicates that a single replacement story would be premature. K12 has a substantial direct path in the aggregate, while the balance between direct and downstream-dependent effects varies markedly across concepts. Negative writing, omission, downstream amplification, and a concept-dependent hybrid remain distinguishable hypotheses.

## Decision

Adopt `docs/post-gate1-causal-mechanisms-plan.md` as the prospective master plan for a possible new research program.

Preserve the original failed gate without threshold changes or claim repair. Use existing data only for explicitly labeled mechanism development and re-identification. If development selects a stable causal operation, require a separately frozen fresh-confirmation contract and untouched evidence before reconsidering the target title.

## Authorization boundary

This decision authorizes documentation and local commits only. It does not authorize:

- new model execution or intervention outcomes;
- construction, qualification, calibration, or access of fresh data;
- reopening Gate 1 or changing Decision 0030;
- the target title or any upgraded scientific claim; or
- push, tag, release, submission, upload, external messaging, or author contact.

Empirical work begins only after explicit user authorization and a committed machine-readable Phase A–B contract.

## Consequences

- The active question changes from “Does K12 carry the complete downstream state?” to “What semantically conditioned causal operation does K12 perform?”
- Full residual reconstruction and the sealed same-concept outcome oracle remain reported diagnostics but are not automatic title gates for a different causal claim.
- Acquisition and causal leverage remain necessary but insufficient.
- Failure to identify a stable operation preserves the causal-localization fallback.
