# Days 26–30: Private Manuscript Sprint

## Objective

Convert the completed research package into a coherent, auditable, private manuscript without changing scientific outcomes or authorizing release.

## Evidence hierarchy

| Tier | Evidence | Manuscript role |
| --- | --- | --- |
| Primary confirmatory | Day 13 frozen safety transfer; Day 14 clean reproduction | Central causal-transfer result |
| Held-out mechanistic | Days 6–12 benign localization, intervention, and transfer | Establish where and how the selected population acts |
| Post-confirmatory falsification | Day 14 robustness and decomposition | Qualify or reject strict circuit hypotheses |
| Prospective intervention | Day 21 fixed non-original route population | Establish mapping-sensitive portable activation transport |
| Prospective behavioral endpoints | Days 22–23; Day 24 descriptive generation | Bound downstream output coupling |

## Day 26 — Freeze scope and structure

- Commit the title, thesis, evidence hierarchy, claim boundaries, outline, figure plan, and claim–evidence map.
- Keep authorship and venue as explicit placeholders.
- Completion gate: every planned headline statement is either mapped to evidence or excluded.

## Day 27 — Build manuscript figures

- Generate six self-contained main figures and machine-readable source tables.
- Keep selected and adverse results visible, including head/MLP decomposition, route heterogeneity, and harmfulness behavioral coupling.
- Create a hash manifest and run image/PDF integrity checks.
- Completion gate: all main figures reproduce deterministically from committed result artifacts.

## Day 28 — Draft Methods and Results

- Write the study design, intervention definitions, data split, inference, and audit procedures.
- Report effect sizes and intervals rather than categorical labels alone.
- Preserve exploratory/confirmatory/prospective distinctions in section headings and captions.
- Completion gate: every numerical main-text claim is traceable to a source table or sealed result.

## Day 29 — Draft framing, discussion, and references

- Write the abstract, introduction, related work, discussion, limitations, and conclusion.
- Cite primary sources for Neural Chameleons, activation monitoring, causal interventions, and representation control.
- Keep novelty wording narrow: this is a causal case study of a released organism.
- Completion gate: all citations resolve and all limitations relevant to headline claims appear in the manuscript.

## Day 30 — Build and audit a private release candidate

- Compile the PDF from a clean manuscript source tree.
- Audit claims, numbers, citations, figure/source hashes, cross-references, build log, repository status, and release prohibitions.
- Record the exact candidate commit and artifact hash after the manuscript source is committed.
- Completion gate: the PDF builds without unresolved references or citations; the package audit passes; no external action has occurred.

## Release boundary

This sprint creates a private candidate only. It does not authorize pushing Git commits, creating a GitHub release, tagging a version, uploading a preprint, submitting to a venue, sending a draft, contacting original authors, or requesting external evaluation.
