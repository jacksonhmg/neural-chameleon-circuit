# Day 36: Phase A–B Development Freeze

## Purpose

This phase translates the post–Gate 1 master plan into a machine-readable development contract. It does not reopen the failed complete-writer gate and does not produce a new mechanism result.

The authoritative specification is [`results/day-36/frozen-phase-a-b-contract.json`](../results/day-36/frozen-phase-a-b-contract.json). If this prose differs from the JSON, the JSON controls.

## Preserved falsification

The original result remains a scientific failure: natural K12 trajectories did not beat the frozen same-concept response-position outcome oracle on held-out full-residual or complete probe-vector prediction. Phase A is allowed to characterize that failure through variance decomposition and centered prediction, but no Phase A statistic can repair or reverse it.

All 13 existing concepts, 1,732 records, released probes, and prior outcomes are development evidence. None is fresh confirmation.

## Phase A populations and folds

- Fit centering, PCA, ridge, and discovery selections on all 256 discovery positives.
- Evaluate centered prediction once on all 610 validation and safety positives.
- Run cross-concept diagnostics across all 866 positives with one complete concept held out from every fitted transform and hyperparameter decision.
- Report all 866 negatives separately where the target is defined; negatives cannot rescue a failed positive gate.

The same-concept oracle is retained unchanged. It remains the proper comparator for the rejected example-specific carrier claim, while the new cross-concept diagnostic forbids access to any target outcome from the held-out concept.

## Phase A estimands

The variance decomposition measures how much layer-12 residual and complete probe-vector variation lies between concept/response-position cells versus within them. Centered K12, normal-state, nonselected-head, and exact-precursor diagnostics then predict target deviations from leave-one-example-out concept/decile means.

A separate outer leave-one-concept-out ridge predicts each concept's ten-decile complete monitor vector. Every PCA basis and alpha choice is fit inside the outer training fold. The semantic baseline uses only the exact precursor's input embedding of the literal concept string.

These analyses are mechanism triage. Full residual `R2` and the failed oracle comparison remain reported diagnostics.

## Phase B absolute operations

At every frozen K12 pre-`W_O` response-token site, run total and frozen-write direct-path variants of:

- zeroing K12 under normal and correctly triggered conditions;
- normal-to-triggered and triggered-to-normal K12 replacement;
- leave-one-example-out normal concept/label/position mean replacement;
- the identical operators in the exact precursor; and
- 32 deterministic rank-, norm-, and temporal-Gram-matched random rotations of each natural K12 delta.

The contrast between triggered zeroing and normal zeroing distinguishes added negative writing from omission of a normal positive write. Replacement effects measure the full condition-dependent operation; they do not substitute for the absolute zero tests.

## Downstream frontier

For each selected-head layer group, patch only that source group. Starting from the frozen-write direct endpoint, progressively release later attention and MLP branches in strict model order while freezing all unreleased branches. Also release each later branch alone. A source/frontier candidate is selected on discovery positives only, with deterministic tie-breaking, then evaluated once on validation and safety positives against same-layer nonselected controls.

These are operator-specific path effects. The aggregate remainder is never called a natural indirect effect.

## Attention operation

For every K12 head and layer group, separately intervene on attention pattern, V states, concept-span QK, and concept-span OV. Source masks distinguish the monitored concept, other monitoring language, original prompt, template/punctuation, and previous response tokens. Attention maps and source accounting remain descriptive unless the matched causal intervention succeeds.

## Frozen mechanism signatures

The JSON freezes quantitative gates for:

- added negative writing;
- gating or omission;
- direct reconfiguration containing both;
- direct monitor writing;
- downstream amplification; and
- a hybrid of direct and amplified operation.

The primary held-out gate requires a substantial point effect and one-sided confidence bound, complete probe-vector recovery, at least seven of nine held-out concepts in the claimed direction, and materially weaker random and precursor controls. Any frontier is selected only on discovery.

Passing Phase A–B permits drafting a Phase C semantic-conditioning contract. It does not authorize Phase C execution or the target title. Failure preserves the existing causal-localization fallback.
