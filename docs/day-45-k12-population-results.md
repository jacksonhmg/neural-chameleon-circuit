# Day 45 K12 Prototype Population Result

The frozen leave-one-example-out concept/response-position prototype passed every prespecified population gate on all 866 existing positive Chameleon examples. The implementation audit also passed. This promotes the prototype as the current minimal operator for K12's **direct** monitor effect; it does not yet establish total-path sufficiency, parameter implementation, or fresh confirmation.

## Frozen causal result

The evaluation contained 13 concepts, induction and rescue directions, the exact natural K12 positive control, the unchanged prototype, and a per-head norm-matched Haar random control. All 5,196 required endpoint rows were present under one execution commit.

Under equal-example-within-concept and equal-concept aggregation, the prototype recovered `1.1215` of the exact natural K12 complete 13-probe-vector direct effect. The frozen 10,000-draw concept bootstrap gave a 95% interval of `[0.9465, 1.4412]`. The random control recovered `0.0963`, so the prototype's recovery advantage was `1.0253`.

Every concept had the prototype own-probe effect in the same direction as exact natural K12, and exact natural K12 had the expected evasion direction in all 13 concepts. Activation-RMS ratios ranged from `0.9630` to `1.0991`.

The result was not confined to one development split:

| Split | Examples | Concepts | Prototype recovery | Random recovery |
|---|---:|---:|---:|---:|
| Discovery | 256 | 4 | 0.9832 | 0.0922 |
| Validation | 448 | 7 | 0.9461 | 0.0703 |
| Safety test | 162 | 2 | 2.0122 | 0.1953 |

## Heterogeneity that must be preserved

Twelve of 13 concepts had recovery between `0.8399` and `1.0530`; their post-hoc descriptive equal-concept mean was `0.9674`. Deception was the exception: recovery was `2.9714`, and its mean own-probe effect was `-9.5099` for the prototype versus `-2.1290` for exact natural K12. The prototype therefore gets deception's causal direction strongly right but over-writes its magnitude. The aggregate `1.1215` estimate should not be described as uniform calibration.

## What this establishes

On the frozen-write direct path, K12 does not need to carry a detailed example-specific evasion trajectory. A target-excluded write determined only by the concept and coarse response position reproduces the exact natural K12 monitor-vector effect across the entire existing positive population and decisively beats an equally sized random direction.

Together with the Day 44 geometric result, the best current operational description is:

> K12 supplies a distributed, concept-conditioned, response-position-dependent write in a non-radial residual direction. The write is largely stereotyped across examples of a concept, directly drives monitor evasion, and is miscalibrated in magnitude for deception when replaced by the concept mean.

This is stronger than saying only that K12 is a causal source. It is still not a claim that K12 literally performs a rotation, that the prototype survives ordinary downstream propagation, or that a particular set of acquired parameters computes it.

## Execution and audit

The H100 execution used 98 deterministic batches and completed the measured matrix in `67.02` seconds, with `19.34 GiB` peak CUDA memory reserved. The real-checkpoint preflight exercised batch size 16 and a 290-token response. Identity error was zero; response tensors, Haar invariants, finiteness, row matrix, target duplication, and hook cleanup all passed. The reducer reproduced byte-for-byte.

The next highest-value test is the same exact/prototype/random comparison on the ordinary total path. If it survives, selected precursor parameter swaps can ask which acquired attention parameters implement this write.
