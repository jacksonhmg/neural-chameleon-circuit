# Day 64: trained-concept, content-untouched final title gate

## Purpose

The new-concept Day 62 panel could not qualify a concept pair and therefore could
not test the complete chain. Day 64 changes only that failed scope choice: it uses
all 11 concepts on which the chameleon behavior is known to exist, while holding
out every evaluation response record from all prior project panels.

The experiment asks whether the already-localized mechanism forms one integrated
causal chain:

`semantic trigger → full-prefix K/V → coordinated K12 → complete probe vector → operational monitor evasion`.

It is a final generalization test over content, not a claim that the concepts were
held out from model fine-tuning.

## Fast execution sequence

1. Freeze all 11 concepts, 16 new positive responses per concept, 128 calibration
   negatives per probe, 64 locked final negatives per probe, the intervention
   matrix, reducers, and every gate before generating a Day 64 model outcome.
2. On one GPU, run a candidate-blind preflight. Then evaluate calibration negatives
   and construct preregistered K/V, K12, and 13-probe development vectors from the
   already-open Day 60 panel. Shared negative activations are evaluated only once.
3. Freeze the exact 1% and 5% FPR thresholds and development-prototype hashes in a
   second committed contract before reading either locked final panel.
4. Run the identical two-direction causal matrix for every concept in both the
   chameleon and exact precursor. Let every unpatched downstream component
   regenerate naturally.
5. Reduce once, independently re-reduce, report every clause and failure without
   tuning, and terminate every project-owned GPU.

Expected wall time is 1–2 hours once a healthy H100 or A100 is allocated. The
authorized ceiling is $100; normal expected cost is below $10.

## Frozen causal matrix

For each concept, the target/donor roles are tested in both directions between its
correct and frozen irrelevant trigger. The matrix includes natural target, donor,
and different-trigger states; donor full-monitoring-prefix K/V into target; a
different-trigger K/V control; a norm-matched orthogonal K12 control; exact target
K12 clamped into donor; target K/V into donor; and exact donor K12 restoration.

The K/V intervention copies joint keys and values from all monitoring-prefix source
positions while retaining recipient response queries and all unselected state. This
is the exact Day 60 operator. The endpoint is always the complete response-mean raw
margin vector of all 13 frozen probes at `resid_post[12]`.

## Title rule

The title is earned only if all seven preregistered clauses pass conjunctively:
acquisition, operation, semantic conditioning, necessity/sufficiency, endogenous
chain closure, restoration, and operational monitor failure. Operational failure is
measured as raw margins and TPR at frozen 1% and 5% FPR thresholds. There is no
aggregate score that can compensate for a failed clause.
