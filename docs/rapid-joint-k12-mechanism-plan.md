## 3. Exact attention algebra

Partition every valid source token into the existing exhaustive atomic regions:

1. monitoring language;
2. named concept;
3. other trigger syntax;
4. original prompt;
5. chat template; and
6. response history.

For selected query head `h`, response position `t`, and region `r`, calculate

```text
m[r]     = sum of attention probability over region r
mu[r]    = attention-weighted regional value mean
C[r]     = m[r] * mu[r]
z[h,t]   = sum_r C[r]
```

The reconstruction must match the natural raw pre-`o_proj` head output. For reciprocal donor `D` and target `T`, build exact regional hybrids:

```text
R = sum_r m_D[r] * mu_T[r]       donor routing, target content
C = sum_r m_T[r] * mu_D[r]       target routing, donor content
D = sum_r m_D[r] * mu_D[r]       exact donor
T = sum_r m_T[r] * mu_T[r]       exact target
```

Allocate the routing/content interaction symmetrically with exact two-player Shapley components:

```text
Delta_route   = 0.5 * ((R - T) + (D - C))
Delta_content = 0.5 * ((C - T) + (D - R))
Delta_route + Delta_content = D - T
```

All algebra and interventions operate jointly across all 12 selected heads. Per-head and per-layer quantities are diagnostics only.
