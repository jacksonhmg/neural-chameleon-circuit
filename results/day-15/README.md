# Day 15: Frozen Site-Shuffling Follow-up

This directory freezes the `site-shuffling-v1` follow-up before any new site-shuffling result is generated.

- `frozen-site-shuffling-plan.json` defines hypotheses, populations, data roles, estimands, controls, inference, selection, confirmation, and interpretation.
- `frozen-mapping-ensemble.json` materializes every permutation used during benign development.
- `freeze-audit.json` verifies deterministic mappings, split counts, selected/null balance, and input fingerprints.

All work remains local. Day 15 does not alter the Day 1–14 result package.
